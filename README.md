# وجد الاصايل 
معرض أعمال وخدمات الرنج والديكور.

هذا المشروع هو موقع تمهيدي/معرض أعمال يُستخدم لعرض خدمات الديكور، المشاريع السابقة، والمنتجات أو الأعمال التي يقدمها المعرض. تم بناء المشروع باستخدام React + Vite + TypeScript، مع تصميم حديث ومتجاوب.

## المميزات

- تصميم حديث وجميل
- واجهة متجاوبة للجوال والسطح المكتب
- عرض خدمات وقطع الديكور والديكور الداخلي
- إمكانية توسيع المحتوى لاحقًا لإضافة المعارض، المشاريع، أو الصور
- أداء سريع بفضل Vite

## التكنولوجيا المستخدمة

- React
- TypeScript
- Vite
- Tailwind CSS
- GSAP
- Lenis
- Express
- Google GenAI

## متطلبات التشغيل

تأكد من وجود التالي على جهازك:

- Node.js 18 أو أحدث
- npm أو yarn

## تثبيت المشروع

```bash
npm install
```

## التشغيل محليًا

```bash
npm run dev
```

سيتم تشغيل المشروع على المنفذ 3000 بشكل افتراضي.

## بناء المشروع للإنتاج

```bash
npm run build
```

## معاينة البناء

```bash
npm run preview
```

## الأوامر المتاحة

```bash
npm run dev      # تشغيل المشروع في وضع التطوير
npm run build    # بناء المشروع للإنتاج
npm run preview  # معاينة النسخة النهائية
npm run lint     # التحقق من TypeScript
npm run clean    # حذف مجلد dist والملفات المؤقتة
```
